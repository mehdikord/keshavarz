# کشاورز

نسخه Mock پلتفرم خدمات کشاورزی با Next.js، React، Tailwind CSS، Zustand و Zod.

## اجرا

```bash
pnpm install
pnpm dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## احراز هویت Mock

- کد OTP برای تمام شماره‌های معتبر: `12345`
- شماره خدمات‌گیرنده دمو: `09123456789`
- شماره خدمات‌دهنده دمو: `09121111111`

## نقشه

نقشهٔ پروژه با [کیت توسعهٔ MapLibre نشان](https://platform.neshan.org/docs/sdk/web/maplibre/neshan-maplibre-gl-js/) (`@neshan-maps-platform/maplibre-sdk`) پیاده‌سازی شده است.

- تنظیمات استایل‌ها (ماهواره‌ای و نقشه): `src/lib/maps/neshan.ts`
- کامپوننت عمومی نقشه: `src/components/shared/neshan-map.tsx`
- انتخابگر موقعیت (پین ثابت وسط نقشه، GPS و حالت تمام‌صفحه): `src/components/shared/map-picker.tsx`
- حالت «نقشه»: استایل Light خود نشان.
- حالت «ماهواره‌ای» (پیش‌فرض): نشان تصویر ماهواره‌ای ندارد؛ تصویر ماهواره‌ای پارسی‌مپ زیر خیابان‌ها و نام مکان‌های خود نشان قرار می‌گیرد، پس نام‌ها دقیقاً همان نام‌های حالت نقشه هستند (`src/lib/maps/satellite-imagery.ts`). پیش‌نمایش‌های کوچک لیست‌ها (`satellite-thumb.tsx`) فقط تصویر ماهواره‌ای دارند.
- کلید وب نشان در `NEXT_PUBLIC_NESHAN_MAP_KEY` و توکن تصویر ماهواره‌ای پارسی‌مپ در `NEXT_PUBLIC_PARSIMAP_MAP_TOKEN` قرار می‌گیرد؛ پس از تغییر آن‌ها سرور dev را دوباره اجرا کنید.
- کلید نشان به دامنه محدود است: دامنهٔ محصول (و `localhost` برای توسعه) باید در پنل نشان برای کلید ثبت شده باشد، وگرنه کاشی‌ها با خطای 484 رد می‌شوند. آدرس `127.0.0.1` پذیرفته نمی‌شود؛ در توسعه از `localhost` استفاده کنید.
- طبق شرایط نشان و پارسی‌مپ، لوگو و متن attribution پایین نقشه نباید حذف شوند.

## اپلیکیشن وب پیش‌رونده (PWA)

کشاورز روی اندروید و iOS مثل یک اپلیکیشن بومی نصب می‌شود (آیکون روی صفحه اصلی، اجرای تمام‌صفحه، صفحه شروع، میان‌برها).

| بخش | فایل |
| --- | --- |
| مانیفست (نام، آیکون‌ها، میان‌برها، اسکرین‌شات‌ها) | `src/app/manifest.ts` → `/manifest.webmanifest` |
| رنگ‌ها، صفحه‌های شروع iOS | `src/lib/pwa/config.ts`، `src/lib/pwa/apple-splash-screens.json` |
| سرویس‌ورکر (کش، صفحه آفلاین، Push) | `public/sw.js`، `public/offline.html` |
| ثبت سرویس‌ورکر و اعلان به‌روزرسانی | `src/components/pwa/pwa-runtime.tsx` |
| برگه نصب (اندروید: پنجره نصب بومی، iOS: راهنمای مرحله‌به‌مرحله) | `src/components/pwa/install-sheet.tsx` |
| نشانگر آفلاین، پوشش نوار وضعیت iOS | `src/components/pwa/offline-indicator.tsx`، `status-bar-scrim.tsx` |

- **آیکون‌ها و صفحه‌های شروع** از روی نشان جوانه ساخته می‌شوند: `pnpm generate:icons` (آیکون `any` و `maskable`، آیکون اپل، `favicon.ico`، نشان اعلان، آیکون میان‌برها و صفحه‌های شروع همه آیفون‌ها و آیپدها).
- **راهبرد کش:** فایل‌های `/_next/static` کش‌اول، تصاویر و فونت‌ها stale-while-revalidate، صفحات شبکه‌اول با صفحه آفلاین. `/api`، `/admins` و داده‌های RSC هرگز کش نمی‌شوند.
- **به‌روزرسانی:** هر build یک نسخه تازه (`APP_BUILD_ID`) دارد؛ اپ نصب‌شده آن را تشخیص می‌دهد و با یک اعلان «به‌روزرسانی» نسخه جدید را بدون قطع کار کاربر فعال می‌کند.
- **رنگ نوار وضعیت** برای هر بخش جدا تنظیم شده (`viewport.themeColor` در layout هر بخش) تا با بالای هدر یکی شود.
- **اسکرین‌شات‌های فروشگاهی (اختیاری):** با قرار دادن `home.png`، `search.png`، `requests.png` (۱۰۸۰×۱۹۲۰) و `wide.png` (۱۹۲۰×۱۰۸۰) در `public/screenshots/` پنجره نصب غنی اندروید فعال می‌شود.
- سرویس‌ورکر فقط در **production** ثبت می‌شود. برای آزمایش: `pnpm build && pnpm start`. نصب PWA به **HTTPS** نیاز دارد (به‌جز `localhost`).
