## تسک‌ها

### Micro-interactions

- [ ] دکمه‌ها: `active:scale-95`
- [ ] کارت‌ها: `hover:shadow-md` (desktop)
- [ ] Page enter: `animate-fade-in`
- [ ] Tab switch: slide transition
- [ ] Dock icon bounce on active

### Visual polish

- [ ] Consistent border-radius همه کارت‌ها
- [ ] Icon sizes یکسان در هر context

### تم کشاورزی

- [ ] Illustration/svg در Empty States
- [ ] Pattern background در hero sections

### Accessibility

- [ ] `aria-label` روی Dock icons
- [ ] Focus visible
- [ ] Contrast ratio ≥ 4.5:1

### Performance

- [ ] `dynamic import` برای recharts
- [ ] `next/image` برای assets
- [ ] lazy load صفحات سنگین
