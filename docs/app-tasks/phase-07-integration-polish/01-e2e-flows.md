# ۷.۰۱ — جریان‌های E2E

> **فاز:** ۷ · یکپارچه‌سازی  
> **اولویت:** P0

---

## سناریوهای تست دستی

### سناریو ۱: جریان اصلی (Happy Path)

1. [ ] Login `09123456789` + OTP
2. [ ] Consumer: ثبت زمین (اگر ندارد)
3. [ ] Consumer: جستجوی «کاشت گندم» برای زمین
4. [ ] نتایج: علی + حسن نمایش داده شوند، رضا (بدون اشتراک) نه
5. [ ] ارسال درخواست به هر دو
6. [ ] Logout → Login `09121111111` (علی)
7. [ ] Provider: تب جدید → قبول
8. [ ] Logout → Login consumer
9. [ ] درخواست → in_progress، شماره علی نمایش
10. [ ] Consumer: پایان کار → completed
11. [ ] Provider reports: درآمد به‌روز

### سناریو ۲: رد درخواست

1. [ ] Consumer ارسال به حسن
2. [ ] Login حسن → رد
3. [ ] Consumer نتایج: حسن غیرفعال + پیام رد

### سناریو ۳: لغو pending

1. [ ] Consumer درخواست pending
2. [ ] لغو → cancelled
3. [ ] Provider لیست جدید خالی

### سناریو ۴: لغو in_progress

1. [ ] درخواست in_progress
2. [ ] Provider لغو با دلیل
3. [ ] Consumer: cancelled + دلیل نمایش

### سناریو ۵: اشتراک

1. [ ] Login provider بدون اشتراک
2. [ ] جستجو → نیاید
3. [ ] خرید اشتراک
4. [ ] جستجو → بیاید

### سناریو ۶: Dual role

1. [ ] یک کاربر هم provider هم consumer
2. [ ] خودش در نتایج جستجوی خودش نیاید
